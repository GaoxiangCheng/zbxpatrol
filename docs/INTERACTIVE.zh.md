<a id="start"></a>
## 1. 进入与首次初始化

终端直接运行（不带子命令）：

```bash
zbxpatrol        # 或 ./zbxpatrol
```

- 仅在**真实终端（TTY）**可用；被程序调用/管道时自动禁用并提示（见 CLI 文档）。
- **首次运行**检测到无配置时进入初始化：依次提示输入 Zabbix 地址、用户名、密码（不回显）、是否跳过证书校验、时区；**验证连通成功后**保存到 `~/.zbxpatrol/config.env`（权限 600），此后所有命令免配置。

<a id="input"></a>
## 2. 通用输入规则（任意层级可用）

| 输入 | 作用 |
|---|---|
| `1`、`2`… 或 `a`、`b`…（a=1） | 选择对应编号的菜单项 |
| `?` | 显示当前层级帮助（可输入内容 + 通用命令），随后自动重印「可输入」提示行 |
| `q` | 返回上一层 |
| `exit` / `quit` | **退出整个向导**（任意层级直达） |
| `m` | 跳转到主菜单（浏览模式下可用） |
| `g` | 跳转到群组选择层（浏览模式） |
| `h` | 跳转到主机列表层（浏览模式） |
| 空回车 | 静默重新提示（不报错） |
| `Ctrl+C` | 强制退出 |

**Tab 补全**：输入框按 Tab 列出候选项（**最多 12 个**，防刷屏），唯一候选自动补全。候选只包含**数据项**（群组名 / 主机名 / 监控项 key），来自 Zabbix 并在会话内缓存。每个输入点上方有灰色「可输入：…」提示行说明当前能填什么。

<a id="levels"></a>
## 3. 层级结构与路径前缀

提示符始终带层级路径，例如：

```
[主菜单] >
[主菜单>浏览] >
[主菜单>浏览>全部主机] >
[主菜单>浏览>全部主机><主机名>] 新key >
[主菜单>报表] >
```

主菜单结构：

```
主菜单
 1) 浏览巡检数据（群组 → 主机 → 指标）
 2) 生成巡检报表
 3) 查询指标
 4) 连通性自检
```

<a id="browse"></a>
## 4. 浏览巡检数据（分级下钻）

### 4.1 群组层 → 主机层

- **群组列表**：含「全部主机」+ 全部群组，分页显示（每页 50 条）；
- 选定群组后进入**主机列表**（含 IP 与系统类型 `[Linux]/[Windows]`），同样分页/过滤；
- 列表数据**会话内缓存**：一次加载，之后切换层级秒开，不重复请求。

### <a id="hostmenu"></a>4.2 主机上下文（选定主机后停留在此）

```
主机 <主机名>
 1) 查看监控项（过滤/分页）
 2) 查看趋势图（CPU/内存/磁盘/自定义监控项）
 3) 快速巡检（单机日报，仅控制台）
 4) 查询自定义 key
```

- 完成任何操作都**回到本菜单**，换功能不用重新选群组/主机；
- `q` 返回主机列表，`g` 返回群组层，`m`/`exit` 退出。

### <a id="chart"></a>4.3 趋势图（连续模式）

1. 选指标：`1 CPU / 2 内存 / 3 磁盘 / 4 自定义监控项`（自定义支持**列表选择**或**直接输入**）；
2. 选时间：日报/周报/月报/年度/**自定义起止**；
3. 出图后输入框停留原地，可**直接输入新 key 连续看图**：
   - 模糊匹配：**唯一命中直接出图；多个命中进选择列表**（例：输入 `load` 列出 3 个 load 项）；
   - `1/2/3` 快速切 CPU/内存/磁盘；`t` 换时间；`q` 返回。

### <a id="hostquery"></a>4.4 查询自定义 key（连续模式）

- 输入 key（单个→智能解析：唯一→直接查询，多命中→列表；多个逗号分隔→按原文查询）；
- `t` 换时间；**时间在连续查询间自动记住**；`q` 返回主机菜单。

<a id="report"></a>
## 5. 生成巡检报表

流程：范围（全部/群组多选/主机多选，可先过滤）→ 时间 → 评分严格度 → **附加自定义指标**（跳过/列表选择/输入通配）→ 输出方式：

| 选项 | 结果 |
|---|---|
| 1 | 控制台彩色表格 + Excel 文件 |
| 2 | 仅控制台表格（不生成文件） |
| 3 | 仅 Excel |
| 4 | 控制台 + CSV 文件 |
| 5 | 控制台 + JSON 文件 |

评分严格度：**宽松（基准 90%）/ 标准（80%）/ 严格（70%）**——基准即高危线，全部百分比阈值联动（详见 README 评分表）。

<a id="query"></a>
## 6. 查询指标

1. key 来源：**从监控项列表选**（先过滤缩小，再多选）或**直接输入**（支持通配 `net.if*`）；
2. 范围：全部/群组/主机；
3. 时间：五种预设 + 自定义；
4. 输出：控制台表格（含趋势火花线）/ 可选保存 CSV；
5. 查询完可选：**继续查询（同范围）** / 更换范围 / 返回主菜单。

<a id="lists"></a>
## 7. 列表操作（分页选择器通用）

提示行示例：`可输入：编号或名称（唯一→直接选中；否则按输入立即过滤）| n/p 翻页 | f 改过滤 | ? 帮助 | exit 退出`

| 输入 | 作用 |
|---|---|
| 编号 | 选择当前过滤后的第 N 条 |
| 条目文本（可 Tab 补全） | **直接输入即智能匹配**：精确/唯一前缀/唯一包含 → 立即选中；**多条命中 → 按输入立即过滤列表并提示「已按 “xx” 过滤：匹配 N 条」**；无命中 → 保留当前过滤并提示 |
| `n` / `p` | 下一页 / 上一页（每页 50 条） |
| `f` | 显式修改/清除过滤子串（与直接输入等效） |
| `all`（多选场景） | 全选 |

**多选**输入格式：`1,3,5` 或 `all`。
